# RAG

Notebook-first retrieval-augmented generation (RAG) workspace.

This repo is organized as a learning path: start with ingestion, move through chunking and retrieval, then compare dense, sparse, hybrid, reranked, and history-aware search.

## What is here

- `0_dataIngestion/` - source notebooks for document, text, CSV, JSON, Excel, and database ingestion
- `1_StoringData.ipynb` through `9_historyAwareRetriver.ipynb` - the main RAG progression
- `data/` - sample source files used by the notebooks
- `chroma_store/` - local vector store output generated by the notebooks

## Quick start

1. Create an environment with Python 3.12 or later.
2. Copy `.env.example` to `.env` and add your API key.
3. Install dependencies with your preferred tool, for example `uv sync` or `pip install -r requirements.txt`.
4. Open the notebooks in order and run them top to bottom.

## Notes

- `data/` contains both source documents and some generated examples, so only the persistent outputs are ignored.
- `chroma_store/` is local state and should be recreated from the notebooks rather than committed.
